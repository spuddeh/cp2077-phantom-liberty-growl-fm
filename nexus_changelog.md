# Changelog

### [v1.0.1]
- Fix: Restore Nebula's track no longer goes missing from Growl FM beside this mod. Both play with no patch.
- Fix: other mods that edit the game's audio data at load no longer lose their changes beside this mod.
- Note: the Restore Nebula Compatibility Patch is no longer needed; delete it if you installed it.
- Note: now requires AudioXL 0.4.3 or newer. With an older AudioXL, redscript reports a compile error at launch.

### [v1.0.0]
- First release. Adds Phantom Liberty to 89.7 Growl FM, in normal rotation.
- Plays the credits recording already in your game, with the silence at each end trimmed. The mod
  ships no audio.
- Shows as Dawid Podsiadło, P.T. Adamczyk - Phantom Liberty, in every language the game ships.
- Works alongside Hardest to Be on Growl FM and Restore Nebula, which also add tracks to the
  station. Restore Nebula needs the Restore Nebula Compatibility Patch from Hardest to Be on Growl
  FM's optional files; that patch covers this mod too and does not need Hardest to Be installed.
